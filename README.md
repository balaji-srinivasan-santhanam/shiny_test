## Overview 

In this repository, we provide code that enables an interactive web-application (https://balajisanthanam-rbp-modules.share.connect.posit.cloud/) for the user to explore the effect of post-transcriptional gene regulatory modules in stratifying patient survival. This builds on our previous work wherein we presented a computational framework for the unbiased discovery of perturbations functionally coherent gene modules that are predictive of patient survival and to facilitate systematic comparisons with conventional clinically used features in cancer.
